## Sourcing notes

- **healthfrog.in was the source, and it rate limited mid run.** Its dentist directory carries clean
  HTML with clinic name, address, landline and mobile, state and city pages
  (`/doctor/dentists/maharashtra/nagpur`, `/doctor/dentists/gujarat/vadodara`), which makes it the
  best phone bearing source found so far. All five Nagpur leads were captured from it before
  roughly 20 requests tripped a "Human Verification" wall (http 200 but a CAPTCHA body). After that
  the same URLs returned a 307 to the verification page, so healthfrog is closed for the rest of this
  run. This is a **single source miss, not two in a row**, so per the skill no broken source
  notification was sent.
- **Vadodara returned zero leads, and the reason is access, not the city.** The Vadodara dentist
  list is 50 clinics and was read (names only) before the healthfrog block, but every clinic page
  that carries the phone number was behind the CAPTCHA wall, and no second phone bearing source was
  reachable inside budget. Per the rule "no contact path, no lead" none were filed. The names are
  listed at the end of this note for a future run once healthfrog is reachable again or a second
  source is found.
- **Two Nagpur clinics were tested and killed.** Aayush Dental Clinic And Orthodontic Care Centre
  (Dhantoli) owns aayushdentalclinic.com, and Chandak Multispeciality Dental Clinic (Dhantoli) owns
  chandakdental.in, both confirmed live and Nagpur correct, so neither is a lead. A third, Dr Bhutada
  Dental Gum Care and Implant Clinic (Ramdas Peth), surfaced its own site dentistinnagpur.com/bdc/ on
  a name search, so it was dropped too. This is the check working as intended: the DNS sweep alone
  would have kept Chandak (chandakdental.in resolves) if the domain had not been fetched and read.
- **The known weakness holds.** A clinic on a domain unrelated to its name would be a false positive.
  Aarya is the live example in this batch, where the only same name domain belongs to a California
  practice, and it was kept only after reading that domain and confirming it is not the Nagpur clinic.
  The 60 second phone check before sending still applies to all five.
- **Unverified Nagpur candidates, not filed** (no owned domain resolved but no confirming name search
  within the cap, worth a manual look if healthfrog stays closed): Agarwal Dental Clinic, Wardhaman
  Nagar, 9975233021. The name is generic, so a no-site call could not be made safely, but the
