# Dental leads - 2026-10-08

Cities scouted: Nagpur, Nashik. Searches used: 2/4 (2 WebSearch, 0 WebFetch). Leads: 5 (P1 5, P2 0, P3 0).

City note: the day-of-year rotation (281 mod 20 -> index 1) points at Nagpur + Nashik, both scouted before
(Nagpur 2026-10-04, Nashik 2026-10-03). After 2026-10-07 the built-in city list is now fully covered: 17 of
the 20 cities have been scouted at least once and the other 3 (Jaipur, Indore, Coimbatore) sit in the
operator's private no-website seed (`rohitctrl/india-dentist-leads`), so the old "skip a seen city, move to a
net-new pair" rule can no longer be satisfied. This run therefore re-scouted the rotation pair itself and
de-duplicated at clinic level: the 8 clinics already in the seen LRU (Nagpur: Ataras, Dhanwant, Daftari,
Cosmo Care, Aarya; Nashik: Great Smiles, Swanand, Dr Sagar Sonar) were skipped. All 5 leads filed below are
net-new. Nagpur and Nashik each hold 40-plus dental listings on the source, so re-scouting is not a dead end.

Source method this run changed, see the sourcing notes. Every lead cleared three checks: no name-derived
domain resolves (8 TLDs per clinic), a name search returns directory and aggregator pages only, and a
homepage probe of any domain that did resolve. That third check matters: it is what caught two clinics that
would otherwise have been filed as no-site leads but do have sites on non-name-derived domains.

## Sourcing notes

- **Source this run was healthfrog.in, reachable and fast.** Unlike the 2026-10-07 run, its pages now answer
  in about 1.3s to 3.6s over curl with a mobile user agent. Its dentist directory is at
  `/<doctor|hospital>/dentists/<state>/<city>` and its clinic detail pages at `/doctor/<slug>.html`. Two city
  dentist pages were read (Nagpur 41 listings, Nashik 43 listings) and 16 clinic detail pages were fetched.
  No CAPTCHA, no rate limit wall this run.
- **The no-site check was strengthened, and it caught two near-misses.** Beyond the usual DNS sweep of
  name-derived domains (8 TLDs per clinic), every resolving domain was fetched and classified, and every
  candidate was name-searched via the DuckDuckGo HTML endpoint (curl, not the WebSearch cap). Two clinics
  that passed the DNS sweep were dropped because a name search found a real site on an unrelated domain:
  **Dr Bhutada Dental Gum Care & Implant Clinic** (Nagpur) has a full site at dentistinnagpur.com/bdc/, and
  **Dr Dave Smyle Studio** (Nashik) has thesmylestudio.com. Neither domain is name-derived, so a DNS sweep
  alone would have filed both as no-site leads. This is the strongest argument yet for the name search, and
  it is why it is now part of the method.
- **Clinics reached and cleared the DNS sweep but were dropped on the name search or a homepage probe:**
  Endo-Max Dental & Implant Clinic (Nagpur, endomaxdental.com is a live site), Anjana Multispeciality Dental
  Clinic (Nashik, anjanadentalclinic.com is live), Ekdant Dental Clinic (Nashik, ekdantdental.co.in and
  ekdantdentalclinic.org are live), Rutu Dent Bhavsar Dental Care (Nashik, rutudent.com resolves, no readable
  page, treated as the clinic's own and dropped), Care 32 Dental And Implant Centre (Nashik, care32dental.com
  resolves with no http, and an unrelated Care 32 runs in Hyderabad, too ambiguous to call), Smile Health
  Care (Nagpur, generic name, smilehealthcare.in is a pharma company, not the clinic, so the signal cannot be
  trusted), Smiline Dental Clinic (Nashik, has a free smilineclinic.weebly.com page).
- **Held back, clean and ready for a later run (reached in full, cleared all checks, not filed only for the
  five-lead cap):** Safalya Super Speciality Dental Clinic (Nashik, Suyash Park, Rajiv Nagar, 9970181620
  mobile / 0253 2373255 landline, directories only plus a localo.site directory stub) and Panchavati Dental
  Clinic (Nashik, Mate Building, Panchavati, 9323233322 mobile, directories only, though the name is generic
  so it needs the phone check before a send). Both are net-new and could be filed on the next Nashik run.
- **Source data:** healthfrog.in Nagpur and Nashik dentist directories (one city listing page each, 16 clinic
  detail pages), a DNS sweep over 8 TLDs for each candidate, homepage probes of every resolving domain, name
  searches via the DuckDuckGo HTML endpoint, plus 2 WebSearch calls for the finalists. No contact made
