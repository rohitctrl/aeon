# Dental leads - 2026-10-09

Cities scouted: Vadodara, Rajkot. Searches used: 4/4 (3 WebSearch, 1 WebFetch). Leads: 5 (P1 5, P2 0, P3 0).

City note: the day-of-year rotation (282 mod 20 -> index 2) named Nashik + Indore. Nashik was scouted
yesterday (2026-10-08) and Indore sits in the operator's private no-website seed, so neither is net-new.
This run stepped to two unseeded, never-scouted Tier 2 cities with no entry in the seen LRU: Vadodara and
Rajkot. Both are large, dense dental markets.

Source note: **the usual source was not usable this run.** healthfrog.in now serves a JavaScript "Human
Verification" wall on every path (city directories, clinic detail pages, robots.txt, sitemap all redirect to
`/captcha.html`), via both curl and the WebFetch tool. I did not attempt to bypass it. Of the fallbacks,
Justdial, Sulekha (main host), Opendi, bharatibiz and the DDG HTML endpoint all returned blocks or a
challenge, Bing returned unrelated cached results, and OSM dentrist coverage in these cities is sparse. The
one working directory was **yellowpages.webindia123.com** (reachable, fast, no wall). Every lead below was
enumerated from its Vadodara / Rajkot dental clinic category and de-duplicated against the seen LRU.

Method: enumerate the webindia123 dental category for each city, fetch each clinic detail page for phone and
address, then run a DNS sweep of name-derived domains (the clinic name plus .com, .in, .co.in, .net, .org,
.clinic, .care, .dental) and classify every domain that resolves. A clinic is kept only when no name-derived
domain belongs to it. Two of the five were additionally name-searched and confirmed to appear on directories
and aggregators only, with no site of their own (see each lead).

## Sourcing notes

- **healthfrog.in is walled right now.** Every path, including robots.txt and sitemap.xml, 307-redirects to
  `https://www.healthfrog.in/captcha.html`. Both curl and the WebFetch tool hit it. This is the same wall
  that throttled 2026-10-05 and 2026-10-06; it cleared for 2026-10-07 and 2026-10-08 and is back today. No
  bypass attempted. If it is still walled on the next run, that is two consecutive source misses and worth a
  note to the operator.
- **The working source was yellowpages.webindia123.com.** Category pages at
  `/d-py/<state>/<city>/dental-clinics-369/1/` list 11 to 12 clinics each; detail pages at
  `/d-t/<State>/<City>/<Name>/<id>/` carry phone and address. Two city categories were read (Vadodara,
  Rajkot) and 21 clinic detail pages were fetched. Note the shared number `7881769346` appears on every
  detail page, it is a site-wide tracker, not the clinic's, and was excluded.
- **Contact discrimination (weakness of this source).** webindia123 does not show a website field, so
  "no website" cannot be read off the listing. It was reconstructed by the DNS sweep plus domain
  classification below. Listings can also be a few years old, so the mobile before a send is worth a check.
- **Name-derived domain sweep, and what it caught.** Of the 21 clinics, these had a name-derived domain that
  is clearly the clinic's own site and were dropped: **Parekhs Dental Care** (parekhsdentalcare.com, Vadodara),
  **Aries Oro-Facial Dental Clinic** (ariesorofacial.com, Vadodara), **Vraj Dental Clinic**
  (vrajdentalclinic.com, Vadodara). Domains that resolved but belong elsewhere, so the clinic was kept:
  devdental.com (Richmond Hill, Canada), devdental.in (Ghatlodia, Ahmedabad), devdentalcare.in (Kozhikode),
  shraddhadental.com (Tathawade, Pune), shreejidental.com (Nikol, Ahmedabad). Domains that were parked or
  for sale, so the clinic was kept: omnarayan.com, citydentalhospital.com, sahajdental.com (all HugeDomains),
  citydentalhospital.in (gambling site), barodadental.com (empty index), devdentalcare.com and
  swastikdental.com (empty pages).
- **Clinic fetched, no mobile, so not filed:** Arin Multi Speciality Clinic (Vadodara, landline only),
  Gopi Dental Clinic and implant Centre (Rajkot, landline only), Shubham Dental Clinic (Rajkot, no number).
- **Held back, clean and ready for a later run** (cleared the DNS sweep, not filed only for the five-lead
